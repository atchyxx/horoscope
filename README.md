# 🔭 占星ホロスコープ表

生年月日を入力すると、太陽星座・月相・惑星の配置を算出し、今日の運勢と具体的なアドバイスを表示するWebアプリです。単一のHTMLファイルで動作します。

## 機能

- **ホロスコープ**：生年月日から太陽星座・四元素・守護星・誕生日の月相を表示
- **今日の空**：月齢・月相（8相）と、太陽・月・水星〜土星の位置する星座を簡易天文計算で算出
- **今日の運勢**：恋愛・仕事・金運・健康の4分野を星評価し、運気レベルに応じた具体的アドバイスを提示
- **相性判定**：今日の月星座のエレメントとの相性を運気ボーナスに反映
- **ラッキー要素**：カラー・アイテム・ナンバー・方角・時間帯
- ダーク/ライトテーマ自動対応

## 使い方

`index.html` をブラウザで開くだけで動作します。生年月日を入力して「占う」を押してください。

※ 惑星位置は簡易天文計算（平均要素＋主要摂動項）による近似値です。占星術の解釈は伝統的な西洋占星術に基づきます。
